description: Establishes an unfamiliar concept's actual semantic contract before creating or editing instances.
---

Inspect concept properties, containment roles, references, cardinalities, scopes
and constraints through a semantic provider. Corroborate documentation with
existing instances. Resolve behavior methods to their owning concept explicitly;
readable projections and inheritance inspection establish ownership, not source
proximity or matching names.

Read-only. For UML-RT, consult `umlrt-dsl` or `papyrusrt-dsl`; for language aspects,
use the matching existing `mps-*` skill. Treat external languages as dependencies,
not editable task scope. Derive semantic rules from the exact loaded release.

For variability, inspect the real feature model already referenced by the target.
If no evidenced feature represents the requested distinction, report that gap
rather than fabricating a new model or attaching conditions indiscriminately.
When behavior or provider support remains uncertain, stop before guessed edits.
Persist verified reusable knowledge under `.agents/SELF_LEARNING.md`.
